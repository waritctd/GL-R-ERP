# Sales Redesign Review vs shipped code — gap audit (read-only)

Read in full: the 1,610-line review HTML (33 templates, the `ROWS` / `NAV` / `UNREACH` script), the spec, and the JSX of every component named below. Nothing was run; all verdicts come from reading code on `whats-new` (HEAD `2189aa59`).

Path prefix: `FE` = `C:\Users\user\Documents\GitHub\GL-R-ERP\.claude\worktrees\whats-new\frontend\src`

## Headline

- **Built close to the drawing:** งานของฉัน cards, ภาพรวมทีมขาย, visits, expected payments, pipeline import, import worklist, pricing chips, การขนส่ง with undo, Express upload and matching, finance deal page.
- **Not built at all:** the whole deal-detail redesign (S-code stepper, "ขั้นต่อไป" card, 5 tabs, quiet links), the `/tickets` board, the new side menu, and the five deal modals (สร้างดีลใหม่, ย้ายไป S2, พักดีล, ปิดดีล · เสียงาน, ยกเลิกดีล).
- **Those gaps are not "deferred by spec".** The spec never lists the deal-detail page or those modals in §7. Its only related line is §9: "the old `/tickets` list stays reachable". The six deal-modal/tab files' last commit is `8d5f1edf` (2026-11-14, comment shortening), i.e. before the redesign.
- **The managers' board does not exist anywhere.** `DealBoard` is imported only by `MyWork.jsx`, and its card has no owner field, so sales_manager and CEO have no 5-column board on any page.
- **Wording differs throughout:** the review says "งาน" (งานทั้งหมด, งานเงียบ, งานที่ทีมถืออยู่); the code says "ดีล" almost everywhere.
