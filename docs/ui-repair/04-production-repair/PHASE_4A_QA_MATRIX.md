## Not Safely Reproduced

- True-empty ticket list in browser QA. The mock seed data is non-empty; changing
  it during browser QA would not be a user-reachable workflow.
- Live `/tickets` error/retry through Playwright routing. The ticket list is
  served by the in-memory mock module, not a network request that can be safely
  failed. DataTable unit tests and the visual component-state harness cover this
  state instead.
